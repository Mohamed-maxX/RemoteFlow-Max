## 🌟 نظرة عامة (Overview)

**RemoteFlow Max** هو نظام تحكم لاسلكي متكامل يحول أي هاتف ذكي إلى وحدة تحكم مكتبية خارقة للكمبيوتر الشخصي عبر شبكة الواي فاي المحلية (Local Wi-Fi). صُمم النظام من الصفر بأحدث التقنيات لتقديم سرعة استجابة مذهلة مع استهلاك شبه معدوم لموارد النظام، بدعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).

---

## ✨ أبرز المزايا والوظائف (Key Features)

### 🖱️ 1. لوحة لمس فائقة الدقة 120Hz (Precision Trackpad)
* **محرك لمس عالي التردد عبر UDP**: نقل حركات الفأرة بتردد يصل إلى 120 إطار في الثانية دون أي تأخير ملموس.
* **إيماءات متعددة الأصابع**:
  - نقرة بإصبع واحد: كليك شمال (Left Click).
  - نقرة بإصبعين: كليك يمين (Right Click).
  - سحب بإصبعين: تمرير رأسي فائق النعومة (Smooth Scroll).
* **شريط تمرير جانبي سريع (Scroll Strip)**: سكرول لحظي وسلس لتصفح المستندات الطويلة وصفحات الويب.
* **مبدل سرعة وحساسية (DPI Switcher)**: وضع القناص الدقيق `0.25x`، الوضع العادي `1.0x`، والوضع السريع `2.0x`.
* **عجلة التحكم الدوارة (Jog Wheel / Surface Dial)**: عجلة استدارة مخصصة لتحرير الفيديو والتقديم/الترجيع في الخطوط الزمنية.

### 🔊 2. وحدة الصوت والوسائط (Audio & Media Deck)
* **خلاط صوت تفاعلي للنظام والتطبيقات**: التحكم بمستوى الصوت الرئيسي لكل تطبيق نشط على حدة (مثل المتصفح، الألعاب، مشغل الموسيقى).
* **زر طوارئ كتم الميكروفون (Mic Mute Switch)**: كتم والتقاط الميكروفون على مستوى العتاد مباشرة.
* **أزرار وسائط شاملة**: تشغيل/إيقاف، المسار التالي، المسار السابق، وكتم الصوت.

### 🚀 3. منصة الماكرو والاختصارات (Stream Deck & Hotkeys)
* **أزرار ماكرو فورية**: أزرار جاهزة لأهم اختصارات البرامج ومنشئي المحتوى.
* **الحافظة المشتركة (Shared Clipboard)**: مزامنة فورية في الاتجاهين للنصوص والروابط بين الهاتف والكمبيوتر.
* **حاقن الروابط المباشر**: فتح أي رابط فوراً في المتصفح الافتراضي للكمبيوتر بنقرة واحدة من هاتفك.
* **جهاز العرض التقديمي (Presentation Remote & Teleprompter)**: تحكم بشرائح العرض ومرآة قراءة أوتوماتيكية للنصوص.

### 📁 4. مستكشف الملفات والنقل السريع (Bi-directional File Transfer)
* **تصفح أقراص الكمبيوتر**: استعراض محتويات الأقراص (`C:\`, `D:\`) ومجلد التنزيلات.
* **تحميل فوري إلى الهاتف**: نقل أي ملف من الكمبيوتر إلى الهاتف بأقصى سرعة ممكنة عبر الواي فاي.
* **رفع سريع (Quick Drop)**: إرسال الصور والمستندات والملفات من الهاتف إلى الكمبيوتر مباشرة في مجلد التنزيلات.

### 🎮 5. يد تحكم ألعاب افتراضية (Virtual Gamepad & Screen Mirror)
* **جيم باد مدمج**: أزرار أسهم D-Pad، وأزرار ABXY، ومحاور تناظرية (Thumbsticks)، وأزرار الكتف (Bumpers & Triggers).
* **بث الشاشة الحي (Screen Stream)**: مرآة حية لشاشة الكمبيوتر بجودة عالية وتأخير منخفض.

### ⚡ 6. أنظمة التحديث اللحظي المباشر (Live UI & Zero-Touch OTA)
* **تحديث الواجهة بدون APK (Live UI Hot-Reload)**: تعديل ألوان الواجهة وحساسية الماوس والأزرار مباشرة عبر ملف `live_ui_config.json` على السيرفر لتنعكس فوراً على الهاتف.
* **واجهة الويب الفورية (PWA Mirror)**: إمكانية التحكم الكامل وتثبيت التطبيق على الشاشة الرئيسية عبر المتصفح على المنفذ `5058` بدون تثبيت APK نهائياً.
* **تحديث هوائي بنقرة واحدة (In-App OTA)**: فحص الإصدارات الجديدة عبر GitHub وتحميل وتثبيت التحديث مباشرة من داخل التطبيق.

## 🛠️ المعمارية والمنافذ المستخدمة (Architecture & Network Ports)

| المنفذ | البروتوكول | الوظيفة |
| :---: | :---: | :--- |
| **5055** | `UDP` | نقل حركات اللمس الفورية، السكرول، وحركات الفأرة (120Hz) |
| **5056** | `WebSocket` | الأوامر الثنائية، الكيبورد، خلاط الصوت، الماكرو، والـ Live UI |
| **5057** | `UDP Broadcast` | الاكتشاف التلقائي للسيرفر على الشبكة المحلية بدون إدخال IP |
| **5058** | `HTTP / PWA` | مستكشف الملفات، تطبيق الويب الفوري، وتنزيل حزم التحديث (OTA) |

## 🚀 كيفية التثبيت والتشغيل (Quick Start)

### 💻 أولاً: تشغيل سيرفر الكمبيوتر (Windows Host)
1. قم بتحميل الملف التنفيذي المباشر: [`RemoteFlowMax.exe`](https://github.com/Mohamed-maxX/RemoteFlow-Max/releases/latest).
2. شغّل البرنامج بالنقر المزدوج (يعمل في شريط المهام بجانب الساعة `System Tray` بدون شاشة سوداء).
3. سيظهر كود الـ QR وعنوان الـ IP الخاص بجهازك للاقتران السريع.

> **ملاحظة للمطورين**: لتشغيل السيرفر من الكود المصدري للبايثون:
> ```bash
> cd pc_server
> pip install -r requirements.txt
> python main.py
> ```

### 📱 ثانياً: تطبيق الهاتف (Mobile Client)
1. حمّل ملف التطبيق مباشرة: **[RemoteFlowMax.apk](https://github.com/Mohamed-maxX/RemoteFlow-Max/releases/latest/download/RemoteFlowMax.apk)**.
2. ثبّت التطبيق وافتحه، وسيقوم بالبحث عن السيرفر والاقتران به تلقائياً.
3. أو افتح الرابط التالي في متصفح هاتفك للتحكم المباشر عبر الويب دون تثبيت:
   ```
   http://<YOUR_PC_IP>:5058/
   ```

## 🔒 الأمان والخصوصية (Security)
* يعمل النظام بالكامل داخل **الشبكة المحلية (Local Area Network)** ولا يتم إرسال أي حركة مرور أو بيانات مدخلات إلى خوادم خارجية.
* يدعم مصادقة رمز PIN السري للأجهزة لحماية جهازك من الاتصالات غير المصرح بها.
